# OUR BLOCK — Build a Neighborhood Together

Play: https://our-block-1ooe.onrender.com/
Source: https://github.com/dev4-gpt/our-block/tree/codex/cloud-hosting

OUR BLOCK is a persistent cooperative 3D browser game for one to four friends. Instead of competing for the highest score, neighbors work together to turn a small town into a thriving community. Explore six connected districts, earn fictional credits, share supplies and make decisions that affect everyone.

Start by bringing a broken community garden back to life. Inspect the problem, measure what is needed, compare supplies at the market, and choose a compatible repair. Shared purchases need another online neighbor's approval. Carry the part back, fit it, test the water connection and complete the project. Continue by growing and packing produce for market commissions, then bring everyone together for a community evening.

The same shared neighborhood has seven selectable visual worlds: Forest, City, Snowy Mountains, Island & Beach, Space Station, Moon and Mars. Each player can choose their own view while keeping the same map, projects and progress. Outfits adapt automatically, from beachwear and winter jackets to spacesuits. Space Station, Moon and Mars include enclosed translucent growing habitats with automatic sliding entrance doors. These are visual themes rather than gravity, weather or oxygen simulations.

Explore mode supports untimed play. Life mode adds active-day pacing, bills and a ledger review. The server controls movement, inventory and spending, while durable saves and recovery tokens let players return to their seats. Reconnecting does not automatically repeat a purchase. Desktop keyboard controls, click-to-walk, touch controls and an accessible map provide different ways to play.

Built with ChatGPT Work using React, TypeScript, Three.js and a Node.js WebSocket server, with persistent Postgres storage. Cross-device playtests informed improvements to touch controls and connection recovery. The deployed security release passed 97 automated tests and a production build; one Postgres-specific test was skipped. Connection admission has time limits, browser security policies are enabled, and recovery tokens are excluded from shared snapshots.

This is a free-hosted playable prototype. The public server supports four online players total across all towns and may take about a minute to wake. Credits are fictional and have no cash value. Invite links allow someone to request a free seat; they are not confidential private-room authentication. The project demonstrates cooperation and practical decision-making without claiming proven learning outcomes.
